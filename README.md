# venstre-some-bilder

Offentlige bilder til Nordre Follo Venstres innlegg i sosiale medier. Publiseringsverktøyet (Native) henter bildene
herfra.

Her ligger bare bilder som Even har godkjent for publisering. De legges inn idet innlegget planlegges, aldri før.
Kildene, skriptene og arkivet ligger i det private hovedrepoet.
